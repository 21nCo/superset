It was an expedient tradeoff, but it was the wrong tradeoff for DATA-6.

DataFn currently has no single canonical request parser. Validation is fragmented across route handlers:

- Query and mutation use dedicated validators.
- Transactions contain their own wrapped/bare-step discrimination.
- Push, clone, reconcile, and search validate their envelopes independently.
- Several sync routes defer parts of validation to execution functions.

I treated that fragmentation as a reason to add an endpoint-aware structural parser beside the routes. That produced a useful safety improvement over recursive traversal, but it did not satisfy the documented architecture. Nothing fundamentally prevented reuse; proper reuse required refactoring those route validators into a shared, versioned parser first, which I avoided to limit the change’s size.

That caused three architectural problems in PR #164:

- `action + unknown payload` is not a discriminated parsed protocol representation.
- The extractor duplicates protocol-shape knowledge in its own switch, so parser/extractor drift remains possible.
- Application-schema validation is mixed into selector extraction, even though the visitor should operate on already parsed protocol selectors. Schema validation belongs in the parsing/validation stage.

The intended implementation should instead:

1. Define a versioned discriminated union for every supported protocol envelope.
2. Make HTTP routes and transport-neutral execution parse through that representation.
3. Implement selector extraction as an exhaustive visitor over the parsed union.
4. Test each fixture through both parsing and extraction, so adding a protocol variant fails compilation or conformance tests until the visitor handles it.
5. Keep selector extraction structural; application schema checks can happen during parsing but should not be the visitor’s responsibility.

So: there was a real limitation in the existing parser architecture, but it did not justify deviating from the plan. I should have surfaced the required parser refactor and implemented it rather than silently substituting a parallel raw-payload switch.
