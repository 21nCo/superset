# Guides

Step-by-step walkthroughs for shipping a docs site with docsfn on **SvelteKit** or **Next.js**, plus patterns for **customizing** the default UI kit.

## Available guides

- **[SvelteKit integration](./sveltekit)** — Install packages, wire layouts, docs and blog routes, search, and prerendering (matches how this site is built).
- **[Next.js integration](./nextjs)** — App Router pages, static params, metadata, React components, and search.
- **[Customizing components](./customizing-components)** — `DocsContent` component maps, sidebar and chrome overrides, TopBar composition, CSS hooks.

If you are new to docsfn, start with **[Getting Started](../getting-started/)** and **[Configuration](../core-concepts/configuration)** before deep integration.
