# Product Overview

`docsfn` keeps this route in the normal docs collection, so it behaves like a plain markdown page and automatically lands in the `product` sidebar.

## What this section shows

- A docs section rooted at `/docs/product`
- Automatic sidebar matching through `navigation.sidebars.product.include`
- Zero custom route logic beyond the standard docs page loader
