## DatafnFieldSchema

Each field in a resource defines its name, type, and field metadata. Core
mutation validation enforces field types and nullability on the server.

```typescript
type DatafnFieldSchema = {
  name: string;
  type:
    | "string"
    | "number"
    | "boolean"
    | "date"
    | "object"
    | "array"
    | "file"
    | "json";
  required: boolean;
  nullable?: boolean;
  readonly?: boolean;
  default?: unknown;
  enum?: unknown[];
  min?: number;
  max?: number;
  minLength?: number;
  maxLength?: number;
  pattern?: string;
  unique?: boolean | string;
  encrypt?: boolean;
  volatile?: boolean;
};
```

## Field Types

| Type      | TypeScript                | Storage  | Notes                                                                          |
| --------- | ------------------------- | -------- | ------------------------------------------------------------------------------ |
| `string`  | `string`                  | Text     | General-purpose text values.                                                   |
| `number`  | `number`                  | Numeric  | NaN is rejected during validation.                                             |
| `boolean` | `boolean`                 | Boolean  | Strict `true`/`false` only.                                                    |
| `date`    | `string \| number`        | Epoch ms | Accepts ISO 8601 strings or epoch milliseconds. Stored as epoch ms internally. ISO datetimes without a timezone designator are interpreted as UTC, so validation and storage resolve the same instant in any server timezone. |
| `object`  | `Record<string, unknown>` | JSON     | Plain objects only. Arrays are rejected; `null` requires `nullable: true`.     |
| `array`   | `unknown[]`               | JSON     | Array values only.                                                             |
| `file`    | `string`                  | Text     | File reference (URL or path). Validated as a string.                           |
| `json`    | `unknown`                 | JSON     | Any JSON value; `null` requires `nullable: true`.                              |

## Const-safe field builders

Use `field` for reusable fields and `defineSchema` for the complete schema.
Builders return plain `DatafnFieldSchema` objects, preserve literal names and
enum members, and emit explicit `required: false` and `nullable: false`
defaults.

```typescript
import { defineSchema, field } from "@datafn/core";

const id = field.string("id", { required: true, unique: true });
const sharedFields = [
  field.boolean("isStarred", { default: false }),
  field.file("attachment"),
];

export const schema = defineSchema({
  resources: [
    {
      name: "tasks",
      version: 1,
      fields: [
        id,
        field.string("status", {
          required: true,
          enum: ["NOT_STARTED", "IN_PROGRESS", "COMPLETED"],
        }),
        ...sharedFields,
      ],
      indices: { base: ["id", "status", "isStarred"] },
    },
  ],
});
```

Requiredness controls whether the record property is present. Nullability
independently controls whether its value includes `null`. Inline object
literals passed directly to `defineSchema` preserve the same inference.
Explicitly annotating a schema as `DatafnSchema` or a reusable array as
`DatafnFieldSchema[]` widens literal information; use `satisfies` for an
assignability check without widening, or use field builders.

Builder options are specific to each field kind. Incompatible defaults, enum
values, bounds, and misspelled options fail type checking. `name` and `type`
are owned by the selected builder and cannot be overridden.

## Constraints

Constraint metadata is preserved for adapters and generated schemas. Core
mutation validation enforces `min`/`max` bounds for `date` fields (compared
as epoch milliseconds) but does not currently enforce every other
constraint, including enum membership, number bounds, and patterns. Check
the selected storage adapter before relying on those constraints at runtime.

### required

When `true`, the field must be present and non-undefined in insert mutations. Fields with a `default` value satisfy the required check automatically.

```typescript
{ name: "title", type: "string", required: true }
```

### nullable

When `true`, the field accepts `null` as a valid value. By default, `null` is rejected for all types.

```typescript
{ name: "deletedAt", type: "date", required: false, nullable: true }
```

### readonly

When `true`, the field can be set on insert but cannot be modified by subsequent update or merge mutations.

```typescript
{ name: "createdBy", type: "string", required: true, readonly: true }
```

### default

A default value applied when the field is omitted from an insert mutation.

```typescript
{ name: "status", type: "string", required: true, default: "draft" }
{ name: "viewCount", type: "number", required: true, default: 0 }
```

### enum

Restricts the field to a fixed set of allowed values.

```typescript
{ name: "priority", type: "string", required: true, enum: ["low", "medium", "high", "critical"] }
```

### min / max

Numeric range constraints. Apply to `number` and `date` fields.

```typescript
{ name: "score", type: "number", required: true, min: 0, max: 100 }
```

### minLength / maxLength

String length constraints. Apply to `string` fields.

```typescript
{ name: "username", type: "string", required: true, minLength: 3, maxLength: 64 }
```

### pattern

A regular expression pattern the string value must match.

```typescript
{ name: "slug", type: "string", required: true, pattern: "^[a-z0-9-]+$" }
```

### unique

When `true`, enforces a unique constraint on the field across all records in the resource. When set to a string, it defines a named uniqueness group -- fields sharing the same group name form a composite unique constraint.

```typescript
// Simple unique constraint
{ name: "email", type: "string", required: true, unique: true }

// Composite unique constraint -- (orgId, slug) must be unique together
{ name: "orgId", type: "string", required: true, unique: "org_slug" }
{ name: "slug", type: "string", required: true, unique: "org_slug" }
```

### encrypt

When `true`, the field value is encrypted at rest. Useful for sensitive data like tokens or personal information.

```typescript
{ name: "apiKey", type: "string", required: true, encrypt: true }
```

### volatile

When `true`, the field is excluded from sync operations. Volatile fields exist only in the local client store and are not pushed to the server.

```typescript
{ name: "localDraft", type: "string", required: false, volatile: true }
```

## Complete Example

```typescript
import { defineSchema } from "@datafn/core";

const schema = defineSchema({
  resources: [
    {
      name: "users",
      version: 1,
      idPrefix: "usr",
      fields: [
        {
          name: "email",
          type: "string",
          required: true,
          unique: true,
          maxLength: 255,
        },
        {
          name: "displayName",
          type: "string",
          required: true,
          minLength: 1,
          maxLength: 100,
        },
        {
          name: "role",
          type: "string",
          required: true,
          enum: ["admin", "editor", "viewer"],
          default: "viewer",
        },
        {
          name: "bio",
          type: "string",
          required: false,
          maxLength: 2000,
          nullable: true,
        },
        {
          name: "loginCount",
          type: "number",
          required: true,
          default: 0,
          min: 0,
        },
        {
          name: "emailVerified",
          type: "boolean",
          required: true,
          default: false,
        },
        { name: "lastLoginAt", type: "date", required: false, nullable: true },
        { name: "avatar", type: "file", required: false },
        { name: "preferences", type: "json", required: false },
        { name: "settings", type: "object", required: false },
        { name: "favoriteTopics", type: "array", required: false },
        {
          name: "encryptedToken",
          type: "string",
          required: false,
          encrypt: true,
        },
        { name: "localNotes", type: "string", required: false, volatile: true },
      ],
      indices: {
        base: ["email", "role"],
        search: ["displayName", "bio"],
      },
    },
  ],
});
```
